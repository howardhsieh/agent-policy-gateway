# 2026-09-19 — R60: Gateway overhead micro-benchmark

**Item.** R60 (first unchecked item under "Up next"): measure what
mediation costs — per-call gateway overhead (policy evaluation, taint
bookkeeping, history tracking) in microseconds, and its scaling against
rule count, history length, and taint-set size, on seeded synthetic
workloads. Acceptance: an `overhead_benchmark` module +
`docs/benchmarks/overhead.md` with pinned methodology; tests assert only
generous order-of-magnitude bounds so CI stays stable across machines;
R61 cites the numbers.

**Environment note.** `ANTHROPIC_API_KEY` is still absent in this
runner, so the deferred R59 real-model fixture recording stays deferred
(the 2026-09-18 caveat stands unchanged).

## Plan

- **`overhead_benchmark.py`** — reuses the R12 `bench.benchmark` timer
  (perf_counter_ns, warmup, nearest-rank percentiles). Two measurements:
  - **Mediation ladder** (per-call cost through `Gateway.execute` on a
    trivial pure-Python tool, each rung adding one bookkeeping feature):
    `raw_call` → `mediated_allow` (1 wildcard allow rule) →
    `mediated_taint` (tainted input label + spec adds + taint-condition
    rule) → `mediated_history` (`track_history=True` + chain rule, the
    just-appended entry popped after each call so length stays fixed) →
    `mediated_full` (taint + history + no-op audit writer) →
    `value_ledger` rung for the R57 record/lookup round-trip. Overheads
    reported as deltas vs the raw baseline.
  - **Scaling sweeps** (pure `Gateway.decide`, no tool execution):
    rule count *N* (only the last of *N* rules matches — worst-case full
    scan), history length *H* (chain rule whose `no_prior` matcher walks
    the whole recorded history, pre-populated through the public execute
    path), taint-set size *S* (input label with *S* integrity sources +
    spec adds). Sizes 1/16/64/256/1024 by default; synthetic rule names,
    sources, and history entries generated from `random.Random(seed)`.
- **CLI**: `python -m agent_policy_gateway.overhead_benchmark` with
  `--iterations/--warmup/--seed/--sizes/--json/--quick`; text table
  mirrors `apg-bench`'s format.
- **Tests** (`tests/test_overhead_benchmark.py`): structural correctness
  (exact rung names, requested sweep sizes, last-rule-matches, history
  length, label sizes, seeded determinism, JSON/CLI smoke) plus only
  generous order-of-magnitude latency bounds (mean per-call mediation
  well under milliseconds-range ceilings) so CI stays stable.
- **Docs**: `docs/benchmarks/overhead.md` — pinned methodology
  (machine, Python, command, seed), the measured ladder + sweep tables,
  scaling readings, regeneration command; mkdocs nav; design.md R60
  section; CHANGELOG; ROADMAP move.
- **Verify**: `python -m pytest -q`, `python -m ruff check .`, mypy,
  `mkdocs build --strict` all green; Conventional Commit; push
  `HEAD:main`.

  worst-case scanned rules (~0.46 µs/rule) and chain-walked history
  entries (~0.48 µs/entry), **near-flat** in taint-set size
  (~0.05 µs/source); ≤ ~25 µs at every size the R55/R56/R59
  benchmarks actually use. Doc pins methodology, environment, and the
  one-command regeneration.
