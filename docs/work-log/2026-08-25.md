## What shipped

Everything planned. Decisions worth recording (all three now in
`docs/design.md` "AgentDojo adapter (R49a)"):

1. **Refusals return, they don't raise.** The refusal string includes the
   rule id (`"PolicyDenied: refused by rule '<id>': <reason>"`) so R50 can
   attribute refusals straight from episode transcripts; a defense that
   crashed the episode would make utility-under-defense unmeasurable.
2. **Taint accumulates per session.** Deliberately conservative: once
   untrusted content enters the conversation, everything after is treated
   as potentially influenced (threat model A1). Denied *and errored* calls
   leave the label unchanged. Finer tracking is R51/R53 territory.
3. **`_invoke` calls the inner runtime with `raise_on_error=True` and
   forwards tool args as `**kwargs`**, so a REDACT rule masks fields by
   argument name before the runtime sees them, and tool errors are
   re-rendered in the runtime's own `"ErrorType: message"` shape on the
   `raise_on_error=False` path.

## What shipped (Run 2)

Everything planned. Decisions worth recording (now in `docs/design.md`
"AgentDojo suite wiring (R49b)"):

1. **Reader classification is vector-derived and shipped as data.** A tool
   is an untrusted reader iff its return can carry attacker-authored text,
   read off the benchmark's own environment data. The frozensets are the
   policy knob R50 measures; integration tests assert they are subsets of
   the real suites' tools so upstream renames fail loudly.
2. **One shared deny surface.** `policies/agentdojo.yaml` holds one deny
   rule per sink in the cross-suite union (22 rules), all conditioned on
   `taint.any_of: [agentdojo:untrusted]`; untainted calls fall through to
   default-allow. The utility cost of the defense comes only from tasks
   that must read injectable content before a sink (banking's "pay this
   bill" reads the bill file first) — exactly the tension R50 quantifies.
3. **`gate_suite` lazy-imports agentdojo** only when it must build a
   `FunctionsRuntime` itself; a runtime missing classified tools raises
   (drift signal); audit `agent_id` defaults to `agentdojo:<suite>`.

Verified end-to-end against the real `agentdojo` 0.1.35: the example

## What shipped

Everything planned. Decisions worth recording:

1. **Tool errors are not refusals.** A crashing tool classifies as `error`,
   never `refused` — a defense must not get credit for a broken sink.
2. **Pessimistic replay order.** User calls run before attack calls so the
   session label reflects the taint a real hijack would ride on.
3. **`defended` is caller-declared metadata**, not inferred — the same
   plumbing measures bare and gated runtimes, which is exactly the R50
   A/B contract.
4. **Task success is vacuously False with zero user calls** — an episode
   that did nothing must not count as utility.
