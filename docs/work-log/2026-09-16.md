# 2026-09-16 — R57: Per-value taint labels

**Item.** R57 (first unchecked item under "Up next", adopted by the
2026-09-14 plan revision): attach taint labels to *values* — tool-call
outputs and the argument strings derived from them — so a sink decision
can see the label of the value actually flowing into each argument,
carrying both R51 dimensions per value.

## Plan

- **Value-flow API**: new `value_flow.ValueLedger` — records executed
  tool outputs with their per-value labels (exact-match propagation:
  a later argument equal to a recorded value carries that value's
  label; labels join on re-record).
- **Core**: `ToolCall.arg_labels` (per-argument `TaintLabel`s,
  serialized only when present so legacy audit records keep shape).
- **Policy DSL**: `Selector.arg_taint` — per-argument `TaintCondition`
  sub-condition (an argument with no recorded value label matches as
  the empty label); mirrored in the CLI explain trace.
- **Adapter**: `GatedAgentDojoRuntime` gains opt-in `track_values`:
  per-call it looks up argument labels from the ledger, stamps them on
  the `ToolCall`, and after an executed call records the output value
  with `propagate(argument labels, spec)`.
- **Benchmark**: sink calls in the R56 family gain a `payload`
  argument (clean text on benign flows, the read/laundered value on
  covert/exfil attacks) over a value-returning runtime; new
  `apg-value-taint` arm (`policies/comparison-value-taint.yaml`,
  per-argument value rules only) run alongside the six R56 arms with
  `track_values` on for every defended arm. Publish whether it (a)
  separates covert-launder compromise from benign-launder utility and
  closes the chain arms' exfil residual (R56 finding 3), and (b)
  passes benign `secret` while holding `exfil` at 0% (finding 4).
- **Verify/docs**: existing six-arm pins must not move; tests + ruff +
  mypy + mkdocs green; update `docs/benchmarks/comparison.md`,
  `docs/design.md`, CHANGELOG, ROADMAP.

## Result — R57 complete

Implemented exactly as planned; all acceptance criteria met.

- **Mechanism**: `value_flow.ValueLedger` (91 lines), `ToolCall.arg_labels`,
  `Selector.arg_taint`, adapter `track_values` threading with
  `propagate(argument-value labels, spec)` at value scope. Session-label
  behavior is untouched; `track_values=False` (default) is byte-for-byte
  pre-R57. CLI explain traces arg_taint rejections; lint gained the W002
  per-argument contradiction check and the conservative W001 exclusion.
- **Benchmark**: R56 family extended with the payload observable
  (`_ValueRuntime` distinct values, sink `payload` argument, sanitize
  `text` hop) — the six R56 arm matrices are pinned **unchanged** — plus
  the seventh arm `apg-value-taint`:

  | arm | utility | compromise | cv-lau | exfil | secret |
  |-----|--------:|-----------:|-------:|------:|-------:|
  | apg-value-taint | 100% | 0% | 0% | 0% | 100% |

  (a) covert-launder compromise separates from benign-launder utility and
  the chain arms' exfil residual closes (R56 finding 3); (b) benign
  `secret` passes while `exfil` holds at 0% (finding 4). Boundary spelled
  out as new finding 6: exact-match propagation covers mediated
  derivations only — paraphrase re-opens the residual (R59 territory).
- **Verification**: pytest **1493 passed, 2 skipped** (was 1455; +38),
  ruff clean, mypy clean (24 files), `mkdocs build --strict` clean,
  `python -m examples.comparison` all 11 invariants ok.
- **Docs**: `docs/benchmarks/comparison.md` (new table + findings 3–6),
  `docs/design.md` R57 section, `docs/cli.md`, `examples/comparison`
  README/claims, CHANGELOG, ROADMAP (R57 → Done).
