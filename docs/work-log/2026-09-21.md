# 2026-09-21 — R62: Audit-trace export for TraceSig

**Item.** R62 (first unchecked item under "Up next"): APG is the
prevention half of a pair whose detection half is the sibling TraceSig
project (Sigma-style rules over agent tool-call traces). Freeze and
document a **versioned** JSONL trace schema for APG audit logs, ship
`apg audit export --format tracesig` with the field mapping documented
in `docs/`, and commit 2–3 example traces (a benign session, a denied
injection, a laundering chain) under `examples/traces/` that TraceSig
can vendor as test fixtures. Acceptance: exporter + round-trip test;
schema doc; examples regenerated by a committed command.

## Plan

- **`tracesig_export.py`** — the pure mapping layer. Frozen schema
  constants (`TRACESIG_SCHEMA = "apg-audit-trace"`,
  `TRACESIG_SCHEMA_VERSION = 1`); `record_to_event(record, seq)`
  flattens one `AuditRecord` into a Sigma-friendly event (stable
  top-level keys: `ts/tool/agent/call_id/verdict/rule/reason/args`,
  the six per-side label lists always present, derived convenience
  booleans `input_untrusted`/`input_secret`/`flagged`, optional
  `redacted_fields`/`declassified_by`/provenance/`arg_labels`/`prev`
  only when carried); `event_to_record(event)` inverts it **losslessly**
  (round-trip is exact because stored label sets are already canonical);
  `export_events(records)` / `write_tracesig(records, fp)` stream a log.
- **CLI**: `apg audit export LOG [--format tracesig] [-o FILE]` —
  `-` reads stdin (mirroring `audit stats`), `--output` writes a file
  (parent dirs created), exit codes match the audit family: 0 ok,
  2 missing file / unwritable output, 3 malformed log line.
- **`examples/traces/`** — three sessions generated through the *real*
  `Gateway` + `JsonlAuditWriter` with a deterministic clock, each
  committed as `<name>.audit.jsonl` + `<name>.tracesig.jsonl`:
  benign-session (default.yaml; kb_lookup + clean send_email, all
  allowed), denied-injection (default.yaml; web_fetch taints the
  session, send_email denied by `deny-web-to-email`), laundering-chain
  (stateful-chain.yaml, `track_history=True`; untrusted read →
  declassifying sanitize → send_money still denied by the R53 chain
  rule). `python -m examples.traces` regenerates and verifies both
  files per scenario; README documents the narrative.
- **Docs**: `docs/tracesig-export.md` — the frozen schema (version,
  compatibility promise, every field with its audit-record origin, the
  derived fields marked as ignored on import), the export command, the
  regeneration command; mkdocs nav entry; `docs/cli.md` gains the
  `audit export` section (test_cli_docs enforces lockstep).
- **Tests** (`tests/test_tracesig_export.py`): event shape pinned for a
  rich record; lossless round-trip over a battery (legacy-minimal,
  provenance, arg_labels, declassify, chained `prev`); writer/reader;
  CLI stdout/file/stdin/missing/malformed/exit codes; committed example
  fixtures regenerate byte-identical and match their audit sources;
  scenario verdict narratives hold; schema doc mentions the version and
  every event field.
- **Wiring**: CHANGELOG, ROADMAP move, design.md R62 section.
- **Verify**: `python -m pytest -q`, `python -m ruff check .`,
  `python -m mypy`, `mkdocs build --strict` all green; Conventional
  Commit; push `HEAD:main`.
