# 2026-08-31 — R55: Long-horizon stateful adversarial eval harness

**Item.** R55 (first unchecked item, done whole in one run per the
2026-08-25 cadence rule): a harness that replays multi-step episodes as
one persistent session where attacker influence persists across turns,
measured under the existing policies. The R49c scripted-episode machinery,
R49a session taint, and R53 call history are the substrate.

## Plan

- `stateful_eval.py`: `Turn` / `Scenario` (ordered turns of
  `ScriptedCall`s), `run_scenario` replaying through **one persistent
  runtime** — reset the session taint + gateway history once at the start,
  never between turns — with a per-turn taint snapshot. `TurnOutcome` /
  `ScenarioReport` deriving horizon-level metrics (`first_compromise_turn`,
  `taint_persistence`, task success, refusals); `aggregate_scenarios` /
  `ScenarioStats` (utility + armed-denominator `compromise_rate`); JSONL

  real AgentDojo tasks. Duck-typed, imports no `agentdojo`.
- `stateful_benchmark.py`: a deterministic "laundering adversary" family
  (read untrusted → k benign turns → sink as legitimate or injected, in
  direct/launder variants) run over the **real gateway + a tiny in-process
  runtime** — no `agentdojo`, no API keys — under three arms (no-defense,
  input-taint, chain). `main`/`__main__`, text + `--json`.
- Policies `stateful-input-taint.yaml` and `stateful-chain.yaml`: identical
  R52 declassify grant, differing only in input-label vs. call-history sink
  rules.
- Worked example `examples/stateful/` asserting the R55 invariants (CI

## What shipped

Everything planned, in one run. The whole R55 harness turned out to be
`agentdojo`-free — it runs the real `Gateway` over an in-process runtime —
so the benchmark numbers are pinned by the ordinary test suite rather than
skipped. Decisions worth recording (all in `docs/design.md` "Long-horizon
stateful adversarial eval harness (R55)"):

1. **The only structural change is that state carries across turns.**
   `run_scenario` resets once at the start (when the runtime exposes
   `reset_taint()`) then replays every turn without resetting between them,
   so the session taint (R49a) and gateway call history (R53) accumulate
   over the whole horizon. That persistence is exactly what a long-horizon
   adversary tries to outlast or launder, and what a per-episode reset
   erases.
2. **New horizon-level metrics.** `first_compromise_turn` (*when* the
   session was first breached), `taint_persistence` (longest span in turns
   a source stayed live — first appearance through last, so it shrinks
   correctly across a mid-session declassify), plus per-turn taint
   snapshots. `compromise_rate` uses an armed-scenario denominator, the
   stateful analogue of R50's ASR.
3. **The benchmark shows what a single episode hides — the R53 note, now
   measured.** Both defended arms share the identical declassify grant;
   only the sink rule differs. `apg-input-taint` stops every *direct*
   attack (0%) but the mid-session `sanitize` declassify launders the
   *attack* too — compromise jumps to **100%** on laundered scenarios,
   because a laundered attack sink and a legitimately recovered user sink
   both arrive with a clean label. `apg-chain` holds at **0%** across the
   whole horizon (the read's history entry survives the declassify), at a
   utility cost (33.3% vs 66.7%). That utility/robustness split is the
   input to R56.
4. **Still framework-agnostic and wired to the real suites.**
   `scenario_from_suite` composes a long-horizon scenario from real
   AgentDojo tasks; an integration test runs one through `gate_suite` and
   confirms the turn-1 read's taint is still live at the final turn. A
   model-in-the-loop long-horizon eval remains future work; R55 is the
   stateful dimension.
