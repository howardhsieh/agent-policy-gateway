## Roadmap item

**R42. `apg audit stats --csv-section {verdicts,rules,tools,agents}`.** Extend the
R40 CSV export beyond verdict counts: a `--csv-section` choice selects which
breakdown to emit as CSV (the existing verdict table, or the top-N

## Plan

  top_rules=None, top_tools=None, top_agents=None)` helper in `audit.py`, next to
  `audit_stats_csv`, reusing `_pct`, `_top`, `_NO_RULE`, and `_NO_AGENT`.

  `--csv-section` without `--csv` with a clear stderr message and exit 2.
- Export `CSV_SECTIONS` and `audit_stats_section_csv` from `audit.py` and the
  package `__init__`.
- Tests in `tests/test_audit_stats.py` covering each section, the unchanged
  verdicts default, ordering/top-N, sentinels, empty log, and the CLI paths.

## Notes / decisions

- **Byte-for-byte parity by delegation.** Rather than re-deriving the verdict
  table inside the new helper, `section="verdicts"` calls `audit_stats_csv`
  directly. The R40 contract is then structurally impossible to drift from, and
  the parity is asserted by a test comparing the two call sites' output.
- **`--csv-section` requires `--csv`.** The flag only shapes the CSV renderer, so
  passing it under the text or `--json` renderer would silently do nothing.
  Rather than implying `--csv` (which would make `--csv-section tools --json` an
  ambiguous request), the subcommand rejects the combination with
  `apg: --csv-section requires --csv` on stderr and exit 2 — the same code and
  shape as the existing `-` mixed with file paths check.
- **Percent basis.** Each list row's `pct` is the entry's share of the filtered
  record total (the same denominator the verdict table and `audit_stats_dict`
  use), not a share of the truncated top-N — so a `--top 1` view still reports a
  percentage that is comparable across sections.
- **Minimal CSV quoting.** Verdict names are bare identifiers, but rule ids, tool
  names, and agent ids come from the log and are arbitrary strings. A small
  `_csv_field` helper quotes (RFC 4180 style, doubling embedded quotes) only when
  a field contains a comma, quote, CR, or LF, so ordinary identifiers — and the
  `(default - no rule)` / `(unattributed - no agent_id)` sentinels — stay bare.
- **Baseline note.** The first baseline `pytest` run of the day errored during
  fixture setup with `FileExistsError: /tmp/apg-pytest` — a stale, non-removable
  `--basetemp` directory left in the sandbox, not a repository fault. Re-running
  with a fresh unique basetemp gave a green baseline; the same convention was
  used for every verification run below.
