## What shipped

Implemented as planned, with two decisions worth recording (both now in
`docs/design.md`):

1. **Share deltas are the difference of the *printed* shares**, not of the
   exact ratios — so `33.3% -> 16.7%` reports `-16.6` and the arithmetic on
   the page always checks out. The CI gates keep the opposite convention on
   purpose: `audit_flagged_share` / `audit_allow_share` threshold the exact
   share, because a value a hair over the limit must still trip. Display
   rounds; decisions do not. Negative zero is normalized so an unchanged line
   reads `+0.0`.
2. **`audit diff` is a report, not a gate.** No `--fail-*` flag, and exit `0`
   whether or not anything moved, mirroring `policy diff`. Thresholding a
   *delta* needs an acceptable-drift policy the project does not have yet.

Also worth noting: movement entries are ranked by *how much they moved*, not
by hit count — appearances and disappearances first (a new rule firing is a
bigger signal than an existing one shifting a place), then largest absolute
rank change, then largest absolute count change, ties by name. Entries whose
count and rank are both unchanged are dropped, so identical logs print
`(no change)` on all three axes rather than a wall of zeros.

are the new test file and 118 are docs; R47 explicitly asks for a pure helper,
a text renderer, a subcommand, and tests covering both the helper and every
