# 2026-08-10 — R45. `apg audit stats --fail-under PCT` allow-share gate

## Roadmap item

**R45. `apg audit stats --fail-under PCT` allow-share gate.** The mirror of
R39's `--fail-over`: exit **6** when the *allow* share of the filtered records
falls strictly **below** PCT percent, otherwise 0 — catching an over-restrictive
policy the way `--fail-over` catches an under-restrictive one.

## Plan

- Add a pure, exported helper `audit_allow_share(records) -> float` in
  `audit.py` (and its `__all__`), mirroring `audit_flagged_share`: an exact
  (unrounded) percentage in `[0.0, 100.0]`, `0.0` for an empty log.
- Add `_fail_under_code(records, threshold)` in `cli.py` returning `6` when the
  allow share is strictly below the threshold, plus a `_gate_code(records,
  args)` combinator so `--fail-over` (exit 5) takes precedence when both trip.
- Add the `--fail-under PCT` argument to the `audit stats` parser
  (`type=float`, `default=None`), so exit codes are unchanged when omitted.
- Route all four renderer return paths (text / `--json` / `--csv` /
  `--count-only`) through `_gate_code` instead of `_fail_over_code`.
- Extend `tests/test_audit_stats.py` with `TestAuditAllowShare` and
  `TestFailUnderGate`: the pure helper, both sides of the threshold, the empty
  log, precedence with `--fail-over`, filter composition, and every renderer.
- Update `ROADMAP.md` (Up next -> Done) and `CHANGELOG.md`.

### Decisions recorded

- **Empty log trips `--fail-under`.** Taken literally from the acceptance
  criteria ("exit 6 when the allow share falls strictly below PCT"): an empty
  or fully filtered-out log has a 0.0 allow share, so any positive threshold
  trips. This is a deliberate asymmetry with `--fail-over` (never over on an
  empty log) and is documented in the docstring, the `--help` text, and a
  dedicated test; `--fail-under 0` keeps an empty log green.
- **Precedence via a combinator, not a merged helper.** `_fail_over_code` was
  left untouched and `_gate_code` layered on top, so R39's behaviour is
  provably unchanged and the precedence rule lives in one place.
