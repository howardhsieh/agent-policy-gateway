# 2026-08-29 — R53: Chain-level policies

**Item.** R53 (first unchecked item, done whole in one run per the
2026-08-25 cadence rule): rules that can reference provenance /
call-history — e.g. "deny `send_email` if any web-sourced call precedes
it in this session". The R30 provenance chains and the R49a
session-cumulative taint are the substrate; the R50 slack any-call
residue (reader-borne exfiltration via `get_webpage`, 60%) is the
benchmark number this should move.

## Plan

- `core.py`: `CallHistoryEntry` — the per-call history record the
  gateway keeps when `track_history=True` (tool, call id, agent id,
  verdict, output label, resource).
- `policy.py`: `chain:` sub-condition on `Selector` —
  `ChainCondition` with `any_prior:` / `no_prior:` lists of
  `PriorCallMatcher` (tool / source / verdict / resource globs over the
  session's recorded calls) and a `provenance:` condition
  (`ProvenanceMatcher` any_of/none_of over the input's provenance
  entries). History-referencing clauses require a history to inspect —
  a gateway not tracking history never matches them (the
  `Selector.resource` precedent). `Selector.matches` /
  `Policy.first_match` gain a keyword-only `history` argument.
- `gateway.py`: `track_history` flag; per-agent-id call history
  recorded on the execute paths (decisions, including denials — pure
  `decide()` records nothing); `call_history()` / `reset_history()`;
  history threaded into rule matching.
- `cli.py`: explain `--prior` (synthetic history entries) + chain
  rejection trace; lint W002 extended to chain contradictions; W001
  stays conservative (a chain rule never claims generality).
- `reload.py`: `WatchedPolicy.first_match` mirrors the new signature.
- AgentDojo: adapter `reset_taint()` also resets gateway history;
  benchmark gateway tracks history; new `policies/agentdojo-chain.yaml`
  (base policy + chain rule closing the reader-borne exfiltration
  channel); chain-arm numbers into `docs/benchmarks/agentdojo.md`,
  slack figures pinned by an integration test.
- Tests `tests/test_chain.py`; docs (`docs/design.md` R53 section,
  quickstart + cli.md), CHANGELOG, ROADMAP move, this log.

## What shipped

Everything planned, in one run. Decisions worth recording (all in
`docs/design.md` "Chain-level policies (R53)"):

1. **History is opt-in gateway state, recorded after the decision.**
   `track_history=True` appends one `CallHistoryEntry` per mediated
   call — every verdict, denials included, since a chain policy may
   care about *attempts* — keyed by `agent_id`, on the execute paths
   only and after redaction is applied, so a call never appears in its
   own history view and the pure `decide()` stays pure (the
   rate-limiter peek/consume precedent).
2. **Untracked history fails closed at the selector.** `history=None`
   (no tracking) is distinct from an empty history: a chain condition
   referencing prior calls — `no_prior` included — does not match at
   all, exactly the `Selector.resource` precedent. Pre-R53 decisions
   are byte-for-byte unchanged unless a deployment opts in.
3. **Matchers glob the prior call's output label.** `source:` matches
   across every dimension of the recorded output label; `verdict:`
   scopes a matcher to executed calls. `chain.provenance` rides the
   R30 chains (needs `track_provenance`, not `track_history`) for the
   finer, value-scoped statement.
4. **The benchmark number moved.** `policies/agentdojo-chain.yaml`
   (baseline + `deny-web-fetch-after-untrusted-read`) closes the R50
   reader-borne exfiltration channel: slack any-call ASR 60% → 40%
   (all 21 injection_task_3 episodes now refused, refusals 296 → 382)
   at **zero** utility cost (4.8% unchanged); other suites identical.
   Honestly documented: on scripted replay an input-taint rule would
   score the same — the chain form survives declassification and sees
   denied attempts, which a label cannot express.
