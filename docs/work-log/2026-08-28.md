# 2026-08-28 — R52: Declarative declassify

**Item.** R52 (first unchecked item, done whole in one run per the
2026-08-25 cadence rule): policy-declared declassification — which
tool may strip which source, in which dimension, under what conditions
— replacing ad-hoc per-spec declassifies as the authority on
declassification.

## Plan

- `policy.py`: new `DeclassifyGrant` pydantic model (`id`, `tool` glob,
  optional `identity` / `resource` / `when:` taint condition, `sources`
  globs, `dimensions` defaulting to both — reusing R51's
  declassify-vs-endorse vocabulary); `Policy` gains a top-level
  `declassify:` list with unique grant ids and a
  `matching_grants(call, resource=...)` helper.
- `gateway.py`: a gateway is *declassification-governed* iff any loaded
  policy carries grants. Ungoverned → byte-for-byte pre-R52 behavior
  (spec declassifies apply). Governed → `ToolTaintSpec.declassifies` is
  inert; matching grants strip their glob-matched sources from their
  declared dimensions of the raised label; fired grant ids are recorded
  on the decision.
- `core.py`: `Decision.declassified_by` tuple, serialized only when
  non-empty (legacy record shapes unchanged).
- `cli.py`: `explain` renders a declassify-grant trace when the policy
  declares grants; `lint` gains W003 (over-broad strip-everything
  grant) and extends W002 to grants whose `when:` can never match.
- `audit.py`: replay prints a `declassify:` line naming fired grants.
- New `policies/declassify-sanitizer.yaml` example; tests
  `tests/test_declassify.py` (schema, matching, gateway governed +
  ungoverned back-compat, serialization, CLI); docs (`docs/design.md`
  R52 section, quickstart + cli.md touch-ups), CHANGELOG, ROADMAP move,
  this log.

## What shipped

Everything planned, in one run. Decisions worth recording (all in
`docs/design.md` "Declarative declassify (R52)"):

1. **Presence of grants flips the authority.** A gateway is
   *declassification-governed* iff any loaded policy carries a
   `declassify:` section; ungoverned behavior is byte-for-byte pre-R52
   (the whole back-compat story, mirroring R51's single rule). Governed:
   per-spec `declassifies` is inert — the policy is the sole authority.
2. **Grants strip directly, no first-match.** All matching grants of all
   policies contribute (union, declaration order); a grant strips only
   from the dimensions it lists, reusing R51's declassify-vs-endorse
   vocabulary. `sources` are fnmatch globs over concrete source names.
3. **Fired grants are audited.** `Decision.declassified_by` names grants
   that actually removed a source, serialized only when non-empty so
   legacy record shapes are unchanged; replay renders a `declassify:`
   line; provenance for stripped sources drops with them.
4. **Redact effects unchanged** (already policy-declared); lint W003
   flags the unconditional strip-everything grant, W002 extends to
   grants whose `when:` is self-contradictory; `WatchedPolicy` grew the
   `declassify` / `matching_grants` duck-type members (caught by the
   reload tests, which is exactly what duck-typing tests are for).
