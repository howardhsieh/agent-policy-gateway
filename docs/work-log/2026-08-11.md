# 2026-08-11 — R46: `docs/cli.md`, a generated-and-checked CLI reference

**Roadmap item:** R46. `docs/cli.md` — a generated-and-checked CLI reference.

## Plan

- Add `docs/cli.md` documenting every `apg` subcommand (`policy validate|explain|diff|lint`,
  `audit stats`), every long option, and the full exit-code table (0–6), plus a short
  note on the sibling console scripts `apg-replay` / `apg-bench`.
- Link the new page from `mkdocs.yml` nav (after Quickstart, before Design) so the
  existing `test_docs_site.py` nav↔filesystem checks cover it.
- Add `tests/test_cli_docs.py`: walk the argparse tree built by `_build_parser()`,
  collect every subcommand path and every long option string, and assert each one
  appears verbatim in `docs/cli.md` — the page cannot silently drift from the parser.
- Add the reverse check too: every `--flag` mentioned in `docs/cli.md` must be a real
  option of some parser (modulo a small allow-list for the `apg-replay` flags), so a
  removed flag is caught as well as an added one.
- Assert the exit-code table documents every code the CLI can actually return (0–6).

## Shipped

`docs/cli.md` is in, linked from the mkdocs nav, and guarded by `tests/test_cli_docs.py`.

Notable choices made autonomously:

- **Exit code 4 is documented even though `apg` never returns it.** The roadmap asked for
  the "full exit-code table (0/1/2/3/4/5)"; in reality `apg` returns 0/1/2/3/5/6 and `4` is
  `apg-replay --verify`'s broken-chain code. Rather than leave a hole in the table, the
  page documents all seven codes and marks `4` as reserved/shared with `apg-replay`, and
  notes `6` (the R45 `--fail-under` gate) which post-dates the roadmap text.
- **The drift check runs in both directions.** Forward (parser → docs) is what the
  acceptance criteria asked for; the reverse (docs → parser, over inline-code spans only,
  with a three-flag allow-list) was added because a *removed* flag is exactly as silent a
  drift as an added one.
- **Negative-tested the guard.** A `--bogus-drift` flag was temporarily added to
  `stats_p`; the suite failed on
  `test_every_long_option_documented[apg audit stats---bogus-drift]`, and the source was
  restored (`git diff src/` empty).
- Documentation-only run: no `src/` changes, no new public exports.
