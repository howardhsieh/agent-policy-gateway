# 2026-08-27 — R51: Dual-label taint (confidentiality + integrity)

**Item.** R51 (first unchecked item, done whole in one run per the
2026-08-25 cadence rule): extend the label model so confidentiality
(secret data must not reach public sinks) and integrity (untrusted data
must not drive privileged actions) are tracked as distinct dimensions
with their own propagation and policy clauses; back-compat for existing
single-set policies.

## Plan

- `core.py`: `TaintLabel` gains `confidentiality` / `integrity` source
  sets alongside the legacy `sources` set (which counts in *both*
  dimensions, preserving current semantics). Canonical form in
  `__post_init__` (a source present in both dimension sets is promoted
  to `sources`), per-dimension `join` / `subsumes`, new
  `all_sources` / `confidentiality_sources` / `integrity_sources`
  properties, `without()` for full-strip, `of_dimensions()`
  constructor. Serialization emits the dimension keys only when
  non-empty so legacy records keep their shape byte-for-byte.
- `taint.py`: per-dimension `propagate` — `adds` / `declassifies` on
  `ToolTaintSpec` are themselves labels, so `declassifies.confidentiality`
  is declassification proper and `declassifies.integrity` is
  *endorsement*; `ToolTaintSpec.of` grows the four dimension kwargs.
  Provenance restriction switches to `all_sources`.
- `policy.py`: `TaintCondition` gains nested `confidentiality:` /
  `integrity:` sub-conditions (`DimensionTaintCondition` with
  any_of/all_of/none_of, matched against that dimension's effective
  set); legacy top-level clauses now match the *union* of dimensions
  (identical behavior for legacy labels).
- `gateway.py`: redact declassify strips from every dimension via
  `without()`; provenance restriction uses `all_sources`.
- `cli.py`: `--taint` accepts `conf:` / `integ:` prefixes; lint W002
  extended to dimension contradictions; W001 shadow check stays
  conservative (a rule with dimension sub-conditions never claims
  generality); explain's taint-rejection message names dimension
  clauses. `audit.py` replay prints dimension annotations when present.
- Tests `tests/test_dual_label.py` (algebra, propagation, policy
  clauses, gateway end-to-end, YAML, serialization back-compat, CLI);
  docs (`docs/design.md` R51 section, quickstart mention), CHANGELOG,
  ROADMAP move, this log.

## What shipped

Everything planned, in one run. Decisions worth recording (all in
`docs/design.md` "Dual-label taint: confidentiality + integrity (R51)"):

1. **The legacy `sources` set counts in both dimensions.** That single
   rule is the entire back-compat story: pre-R51 labels, specs,
   policies, and audit records behave identically, and the R50
   benchmark's blanket policy is untouched. R51 only makes finer
   policies expressible.
2. **Canonical form makes equality semantic.** A source in both
   dimension sets is promoted to `sources` in `__post_init__`, so
   `of("x")` == `of_dimensions(confidentiality=["x"], integrity=["x"])`
   and serialization emits dimension keys only when non-empty (legacy
   JSON shapes byte-for-byte unchanged).
3. **Declassify splits into declassify and endorse.**
   `declassifies_confidentiality` strips the secret and keeps the
   untrustedness (vetted redactor); `declassifies_integrity` is
   endorsement — strips the untrustedness and keeps the secrecy
   (sanitizer). A redact effect's `declassify` remains a full strip.
4. **Top-level taint clauses match the union of dimensions** (the
   fail-closed reading, identical for legacy labels); nested
   `confidentiality:` / `integrity:` sub-conditions match one
   dimension's effective set. Lint W002 got per-dimension contradiction
   checks; W001 stays conservative (a rule with dimension sub-conditions
   never claims generality — missed warnings over false ones).
